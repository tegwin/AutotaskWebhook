# AutotaskWebhook
Autotask Webhook creator


This tool will create webhooks in Autotask everytime a customer and ticket are created, updated and edited.  The webhook URL Can then be used in tools such as n8n. 

You can see an example of this on my Youtube channel.  You can see some information here on how to use it 

# Requirements
You need to have PHP installed locally, or you need to run it on a server where you can use PHP (such as DigitalOcean)
